# 📚 RAG Чат-бот по конспектам курса

Простой и понятный RAG (Retrieval-Augmented Generation) чат-бот для работы с учебными материалами. Загрузите PDF с конспектами, задавайте вопросы и получайте ответы с указанием страниц!

## 🎯 Что это такое?

**RAG (Retrieval-Augmented Generation)** - это техника, которая позволяет языковым моделям работать с вашими собственными данными, а не только с общими знаниями.

### Как это работает:

1. **Загрузка документов** → PDF разбивается на небольшие кусочки (чанки)
2. **Создание embeddings** → Каждый кусочек превращается в вектор чисел
3. **Поиск** → По вашему вопросу находятся похожие кусочки текста
4. **Генерация ответа** → LLM (ChatGPT) отвечает на основе найденных фрагментов

### Практическая польза:

- ✅ Быстро найти нужную информацию перед экзаменом
- ✅ Не листать 100 страниц конспектов
- ✅ Получить краткий ответ с указанием страницы
- ✅ Понимание, как "научить" AI работать с вашими данными

## 📋 Что нужно изучить (по порядку)

1. **Embeddings (векторное представление текста)**
   - Текст → вектор чисел
   - Похожие тексты → похожие векторы
   - См. `vector_store.py` для деталей

2. **Chunking (разбивка документа)**
   - Документ разбивается на кусочки оптимального размера
   - Перекрытие между кусочками сохраняет контекст
   - См. `pdf_processor.py` для деталей

3. **Similarity Search (поиск похожих кусочков)**
   - Вопрос → вектор
   - Сравнение с векторами всех кусочков
   - Возврат самых похожих
   - См. `vector_store.py` → метод `search_similar()`

4. **Генерация ответа через LLM**
   - Найденные кусочки + вопрос → промпт для LLM
   - LLM генерирует ответ на основе ваших данных
   - См. `rag_chain.py` для деталей

## 🔍 Подробное объяснение компонентов

### 1. `pdf_processor.py` - Обработка PDF

**Что делает:**
- Извлекает текст из PDF с сохранением номеров страниц
- Разбивает текст на чанки оптимального размера (1000 символов)
- Добавляет перекрытие между чанками (200 символов) для сохранения контекста

**Почему это важно:**
- Слишком большие чанки → плохой поиск (много лишнего)
- Слишком маленькие → теряется контекст
- Оптимальный размер: 500-1000 символов с перекрытием

**Пример использования:**
```python
from pdf_processor import PDFProcessor

processor = PDFProcessor(chunk_size=1000, chunk_overlap=200)
pages = processor.extract_text_from_pdf("lecture.pdf")
chunks = processor.split_into_chunks(pages)
```

### 2. `vector_store.py` - Векторная база данных

**Что делает:**
- Создает embeddings (векторные представления) текста
- Сохраняет их в ChromaDB (локальная векторная БД)
- Ищет похожие фрагменты по запросу

**Как работают embeddings:**
- Текст → вектор чисел (например, 1536 чисел для OpenAI)
- Похожие тексты → похожие векторы
- Поиск = сравнение векторов (косинусное расстояние)

**ChromaDB:**
- Простая локальная векторная БД
- Не требует установки сервера
- Работает прямо в Python
- Автоматически создает индексы для быстрого поиска

**Пример использования:**
```python
from vector_store import VectorStore

# Использование OpenAI (платно, качественно)
store = VectorStore(use_openai=True)

# Или HuggingFace (бесплатно, локально)
store = VectorStore(use_openai=False)

# Добавление документов
store.add_documents(chunks)

# Поиск похожих фрагментов
results = store.search_similar("Что такое RAG?", n_results=3)
```

### 3. `rag_chain.py` - Генерация ответов

**Что делает:**
- Получает вопрос пользователя
- Находит похожие фрагменты в базе данных
- Отправляет их в LLM (ChatGPT) с инструкцией ответить на вопрос
- Возвращает ответ с ссылками на страницы

**Retrieval-Augmented Generation:**
- **Retrieval** = поиск релевантных фрагментов
- **Augmented** = дополнение промпта найденными данными
- **Generation** = генерация ответа LLM

**Пример использования:**
```python
from rag_chain import RAGChain

rag = RAGChain(vector_store=store, model_name="gpt-3.5-turbo")
result = rag.generate_answer("Что такое машинное обучение?")
print(result["answer"])
```

### 4. `app.py` - Веб-интерфейс Streamlit

**Что делает:**
- Простой и красивый веб-интерфейс
- Загрузка PDF файлов
- Чат с ботом
- Отображение источников (страниц)

**Особенности:**
- История диалога
- Показ релевантности найденных фрагментов
- Выбор модели (OpenAI или HuggingFace)

## 🛠️ Настройки и опции

### Использование HuggingFace вместо OpenAI (бесплатно)

В `app.py` выберите "HuggingFace (бесплатно, локально)" в боковой панели.

Или в коде:
```python
store = VectorStore(use_openai=False)  # Использует локальную модель
```

**Примечание:** Первый запуск скачает модель (~400MB), затем работает полностью локально.

### Настройка размера чанков

В `pdf_processor.py`:
```python
processor = PDFProcessor(
    chunk_size=1000,      # Размер чанка в символах
    chunk_overlap=200     # Перекрытие между чанками
)
```

### Выбор модели LLM

В `app.py` или `rag_chain.py`:
```python
rag = RAGChain(
    vector_store=store,
    model_name="gpt-4",      # или "gpt-3.5-turbo"
    temperature=0.7          # Креативность (0-1)
)
```

## 📚 Примеры использования

### Пример 1: Загрузка одного PDF

```python
from pdf_processor import PDFProcessor
from vector_store import VectorStore
from rag_chain import RAGChain

# Обработка PDF
processor = PDFProcessor()
pages = processor.extract_text_from_pdf("lecture1.pdf")
chunks = processor.split_into_chunks(pages)

# Создание векторной БД
store = VectorStore()
store.add_documents(chunks)

# Создание RAG цепочки
rag = RAGChain(store)

# Задаем вопрос
result = rag.generate_answer("Что такое нейронные сети?")
print(result["answer"])
print(f"Источники: страницы {[s['page'] for s in result['sources']]}")
```

### Пример 2: Добавление нескольких PDF

```python
# Загружаем первый PDF
processor = PDFProcessor()
pages1 = processor.extract_text_from_pdf("lecture1.pdf")
chunks1 = processor.split_into_chunks(pages1)

# Загружаем второй PDF
pages2 = processor.extract_text_from_pdf("lecture2.pdf")
chunks2 = processor.split_into_chunks(pages2)

# Добавляем все в одну базу
store = VectorStore()
store.add_documents(chunks1 + chunks2)

# Теперь можно задавать вопросы по всем документам
rag = RAGChain(store)
result = rag.generate_answer("Что общего между лекцией 1 и 2?")
```

## 🐛 Решение проблем

### Ошибка: "OPENAI_API_KEY не найден"

**Решение:** Создайте файл `.env` в корне проекта:
```
OPENAI_API_KEY=your_key_here
```

Или используйте HuggingFace embeddings (бесплатно, локально).

### Ошибка при чтении PDF

**Решение:** Убедитесь, что PDF не защищен паролем и содержит текст (не только изображения).

### Плохие ответы от бота

**Возможные причины:**
1. Чанки слишком большие → уменьшите `chunk_size`
2. Недостаточно контекста → увеличьте `chunk_overlap`
3. Неправильный промпт → настройте в `rag_chain.py`

### Медленный поиск

**Решение:** ChromaDB автоматически создает индексы. При первом запуске может быть медленнее.
